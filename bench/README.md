# Original validation scripts

The original run scripts and open package manuals are retained here. Machine-specific source paths are replaced with `<ALLMETA_ROOT>` or `<WORK_ROOT>`; set `R_LIBS_USER` to your installed library (conceptually `<R_LIBS_USER>`). No script installs packages.

Run in a separate scratch directory inside this archive when re-executing the original harness. Copy the scripts there first; `reference.R` writes its corpus and references in the current directory and requires the archived versions of metafor and metadat. `secondary-meta.R` also requires meta; `prepare-meta.py` creates its CSV input. The original `run-app.cjs` requires `PLAYWRIGHT_PATH` pointing to an existing Playwright package and installed Chrome. It accepts a page-tree directory and an output JSON filename. Use the archived `app/` tree for the patched page; the original page can be reconstructed by reversing `fix.patch` on a copy of the numerical page, with the validation-only hooks removed if using the original debugger line probes. Never overwrite the archive's source records while rerunning.

The original sequence is reference.R, run-app.cjs, compare.py; then prepare-meta.py, secondary-meta.R and compare-meta.py. Auxiliary original refinement, source-inspection and report-generation scripts are preserved as historical evidence; their diagnostic inputs are not all included. They are not the supported archive entry point. The portable supported numerical re-execution is `Rscript validate.R` from the archive root. `analysis/make_outputs.py` independently reproduces the primary/secondary aggregate counts from final JSON records.

Package manuals describe source mappings and upstream attribution. The reference JSON preserves metafor's own I2 and default PI separately from the app-convention quantities used for comparison.

`ui_smoke.cjs` is an additional archive check using existing Playwright/Chrome, not an original historical script. Set `PLAYWRIGHT_PATH` to your installed Playwright package. Normally serve `app/` at `http://127.0.0.1:8000` first. With `ARCHIVE_ROUTE_FILES=1`, Playwright instead fulfills same-origin requests from exact archive file bytes, avoiding a listening-port conflict. Both modes execute the real archived JavaScript and webR package code; neither substitutes saved statistical outputs. The results JSON labels the transport. Required allmeta Playwright tests were separately run through a real HTTP server.
